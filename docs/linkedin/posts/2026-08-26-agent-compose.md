## Copy

F-Motion’s agent loop is on the site.

Drop a few photos into Cursor or OpenClaw — or just answer a short chat. The
agent asks at most four missing questions, then returns a vertical preview and
the same project as a draft. Keep the file, change one scene, or open the
studio and keep editing.

Chat-only is valid. If there is no media yet, you still get the draft. A
preview renders only after files or licensed stock are actually attached. Host
metering stays one unit for preview, two for final. Pexels and FAL stay your
keys.

This is live alpha, not a commercial launch.

Try it: https://f-motion.com/agents.html
