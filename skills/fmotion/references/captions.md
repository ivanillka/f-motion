# Captions

Short lines that read like speech.

- Sentence case, one line per scene.
- Plain words. No jargon and no all caps.
- Keep the whole line inside the 6% safe inset.
- Prefer a short sentence over two stacked lines.
- For Spoken scenes, write the words the voice will say and let the take set
  the timing.
- The preview and the export print the same size and face. If a line is
  cropped in check, shorten it.
