# Security policy

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting from the public repository's
**Security** tab. Do not open a public issue and do not include credentials,
personal data, or customer media in a report.

Private reporting must be enabled before the first public release. If the
private reporting option is unavailable, publication remains blocked rather
than falling back to a personal address.

Only the latest released minor version is supported until a longer support
policy is published. Private hosted-product incidents are handled by that
product's separate operational process.

See also [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
