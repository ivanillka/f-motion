## Findings considered and rejected (this round)

- Exact-vs-range npm pin policy across api/worker: real but low leverage.
- Full OpenAPI `/v1` resurfacing: needed later; do not block media truth.
- Beatoven / managed FAL / payments / Flutter Web: gated or already rejected.
- CI auto-deploy: defer until images + manual deploy work (008).
- Outbox `SKIP LOCKED` multi-worker claim: follow-up after 009.
- Express stack-scrubbing error middleware + forced loopback bind: small
  follow-ups; optional fold into 008 if touching `start.ts`.
- Gate 0 / payments / Play signing: public-launch only, not private-demo blockers.
- Full in-browser nonlinear/multitrack editor: rejected for now; the focused
  storyboard editor plus portable export covers the need at far lower cost.
- AAF/OMF/native Premiere, Resolve, or CapCut project generation: rejected for
  the first export release; proprietary/complex formats need separate demand
  and compatibility evidence.
- One FCPXML file advertised for every editor: rejected because Premiere does
  not directly import modern `.fcpxml`, and CapCut documents no third-party
  project import.
- Raw Pexels source files in editor bundles: rejected pending an explicit
  provider-rights review; export transformed scene clips instead.
- Client-supplied render dimensions, watermark, codec, or FFmpeg arguments:
  rejected as a trust-boundary violation; profiles remain host-owned.
