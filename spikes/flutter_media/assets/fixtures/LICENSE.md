# Fixture license

The `scene_one.mp4` and `scene_two.mp4` files were generated for this spike with
FFmpeg from solid-color, moving-box, and sine-wave filters. The first fixture
uses three vertically stacked solid-color panels in a deliberately tall frame
as visible Y-crop landmarks; the second uses three horizontally stacked panels
as visible X-crop landmarks. They contain no third-party media and are
dedicated to the public domain under CC0 1.0.

Generation commands are recorded in `docs/spikes/flutter-media.md`.
